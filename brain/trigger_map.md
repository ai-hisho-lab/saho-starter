# 発火表（索引）— 「この言葉が出たら、ここを見る」

秘書AI が**必要な時だけ** grep で引く索引。読み込みっぱなしにはしない（常駐を太らせないため）。
最初は空に近い。**使っていて「あれどこだっけ」が起きたら 1 行足す**。

| この言葉が出たら | ここを見る |
|---|---|
| 業界の言葉・略語が分からない | `brain/glossary.md` |
| 人の名前（◯◯さん） | `context/people/`（フックが所在を教えてくれる） |
| 案件・プロジェクト名 | `context/projects/`（同上） |
| 「前の続き」「どこまでやったっけ」 | `context/log/` の直近ファイル |
| 情報の扱いで迷った | `governance/security.md` |
| 私の振る舞いを直したい | `saho/README.md`（作法の育て方） |

## 足し方
