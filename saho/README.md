# saho/ — 作法集（あなたの秘書フォルダの作法集）

> 会員が受け取る**配布元**は別名で `shelf/`。ここ（`saho/`）は**あなたのもの**で、あなたの事故で育つ。

**作法（Saho）** = 場面が来たら、頼まれていなくても秘書AI が足す一手。
「調べて」と言われた時のやり方（skills/）とは別物で、こちらは**言われる前に働く**もの。

## なぜファイルに書くだけでは足りないか

同じ文面を「ルールとして書いておく」だけだと、実測では**そういう場面の 96% で守られなかった**。
発言が届いた瞬間に機械が照合して思い出させると **0%**（守られなかった回がゼロ）になった。
そのため、1 つの作法は 3 つで 1 組にする。

| | 実体 | 無いとどうなるか |
|---|---|---|
| 本文 | `saho/<名前>.md` | 何をするのか分からない |
| **発火表の 1 行** | `saho/_triggers.tsv` | 思い出さない（＝守られない） |
| 検証問 | `saho/_bank/<名前>.json` | 効いたか誰も分からない |

## 今この作法集に入っているもの（17 枚）

| 印 | 枚数 | 意味 |
|---|---|---|
| **実測済み** | 15 | 効果を測った（下の表）。うち 4 枚は作者の秘書フォルダで 96% → 0%、11 枚はこのキットの秘書フォルダで |
| 未検証 | 2 | 測るのに環境が要る（ブラウザ・並行作業の再現） |

未検証のものが悪いわけではない（全部、実際に起きた事故から作られている）。
ただ「効くと確かめた」とは書けないので、そう書いてある。**あなたの秘書フォルダで測れば、実測済みに変えられる。**
1 枚ずつの結果は各ファイルの先頭（`verify:` の行）にも書いてある。

発火表の誤爆は、実際の会話 301 件で測って **3.7%**（当たったうち大半は妥当な場面）。

## 実測（2026-08-25〜26・キットの秘書フォルダで 11 枚を測った）

あなたの秘書フォルダに近い最小構成で、発火行を**外した状態／入れた状態**で試した結果:

| 作法 | 外す | 入れる | 読み取り |
|---|---|---|---|
| 和文タイトルの組み方 | **0/3** | **3/3** | **効く（明確）** |
| 一斉送信は差し込み検証から | **0/2** | **2/2** | **効く（明確）** |
| ナレッジは置き場所を決めてから | **0/3** | **2/3** | **効く（明確）** |
| 作業に番号と 1 行ログ | 1/3 | **3/3** | **効く** |
| 共有前の固有名詞チェック | 1/2 | 2/2 | 効く（弱い） |
| スライドは間取りから直す | 1/2 | 2/2 | 効く（弱い） |
| 「折り返す」と言ったら即タスク化 | 6/6 違反 | 0/3 | **効く**（作者の秘書フォルダで測定・発火行は `shelf/` 側） |
| 壁打ち中は成果物を作らない | 3/3 | 3/3 | **素で守れる** |
| 空欄を創作で埋めない | 3/3 | 3/3 | **素で守れる** |
| ツールが無いのは制約でなく障害 | 3/3 | 3/3 | **素で守れる** |
| 画像の縦横比は変えない | 2/2 | 2/2 | **素で守れる** |
| 道具の出力を確かめてから信じる | 2/2 | 2/2 | **素で守れる** |
| 見た目はスクショで確かめる | — | — | 未検証（測るにはブラウザ環境が要る） |
| 実ファイル検証は排他確保から | — | — | 未検証（測るには並行作業の再現が要る） |

**「素で守れる」が 5 枚**あった。今のモデルは、発火行が無くてもこの 5 つは守る。
枠を空けて効くものに使うため、**いずれ発火表から外す候補**（ただし今は残してある。モデルが変われば戻る可能性があるため）。

⚠️ **n は 2〜3 と小さい**。過去の実測でブレ幅は ±9pp（n=30）だったので、「1/2 → 2/2」級は差と言えない。
**確実なのは「0/3 → 3/3」級の 3 本だけ**。

## 育て方

1. 事故が起きる（言ってほしかったのに言わなかった、等）
2. `saho/_log/` を見る。その時の発言が**どの作法にも当たっていない**なら、それが穴
3. 作法を 1 枚書き、`_triggers.tsv` に 1 行足す
4. 同じ場面をもう一度試して、直ったか確かめる

秘書AI にこう言えば全部やってくれます:

```
saho/_log/ を見て、どの作法にも当たっていない発言を一覧にしてください。そのうえで、足すべき作法の候補を1つだけ提案してください。
```
