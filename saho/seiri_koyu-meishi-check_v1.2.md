# 目的

伏せたつもりの共有物から個人・企業が特定される事故を、外に出す前に止める。

# 実際に起きた事故

事例紹介を共有用に整えた際、人名と社名は伏せたが、実在の団体名がイベント名・時期と一緒に残っていた。組み合わせれば個人までたどれる状態で検品を通過しかけ、第三者の抜き取りチェックで発覚した。**作った本人と検品者が同じだと見逃す**、という教訓も込みの事故。

# 直前チェック（すべてYesになるまで出さない）

1. 人名・社名だけでなく、団体名・イベント名・地名・施設名も伏せたか（【顧客A】【業界団体B】形式）
2. 業種×地域×時期×規模の「組み合わせ」で個人や企業が絞り込めないか
3. 金額・日付・人数は丸めたか（丸められない事情があるなら利用者に確認したか）
4. 本人（当事者）の掲載許可と、共有先の公開範囲を確認したか（許可が無ければ共有を保留して利用者に依頼。公開範囲が広いほど伏せ方を強くする）

# 実行指示

共有・公開の前にチェックを通す。1つでも怪しければ出さず、該当箇所を具体的に利用者に示す。

# 判断基準

対象は社外・コミュニティに出すものすべて。内部にだけ保管する記録は対象外（内部記録まで伏せ字にすると資産価値が下がる）。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず利用者に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。利用者が「確認済み」と明示した項目を、重ねて確認し直さない。
