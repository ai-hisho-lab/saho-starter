# 目的

枠に合わせた引き伸ばしで画像が歪んだまま確定・納品されるのを止める。

# 実際に起きた事故

スライドの枠に写真の大きさが足りず、枠に合わせて片方向に引き伸ばして配置した。縦横比が変わって被写体が歪んだまま確定しかけた。自動配置ツールの「枠いっぱいに広げる」系の設定でも同じことが起きる。

# 直前チェック（すべてYesになるまで確定しない）

1. 画像の縦横比は元のままか（拡大・縮小は等比だけか）。縦横比は「実際に表示される向き」で測ったか（スマホ写真はEXIFの回転タグで、保存された寸法と表示される寸法が入れ替わることがある）
2. 枠と画像が合わないとき、引き伸ばしではなくクロップ（切り抜き）か枠側の変更で対応したか
3. 人物・ロゴ・文字を含む画像に歪みが出ていないか、表示して見たか

# 実行指示

縦横比を変える引き伸ばしはしない。枠と合わないときはクロップか枠側の変更で対応し、どちらにするか迷う場合は両案を利用者に見せて選んでもらう。

# 判断基準

対象は画像・図版の配置。図形やベタ塗り背景など、伸ばしても情報が壊れないものは対象外。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず利用者に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。利用者が「確認済み」と明示した項目を、重ねて確認し直さない。
