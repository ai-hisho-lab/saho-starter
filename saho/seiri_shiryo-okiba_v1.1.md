# 目的

ナレッジの価値は保存でなく再会で決まるので、「保存したのに、使う場面で参照されない」を防ぐ。

# 実際に起きた事故

師匠と仰ぐ人物から学んだ体系を担当分野の奥に保存していたため、肝心の企画作業で参照されず、成果物を全数作り直しになった。

# 直前チェック（保存する前に、すべてYesにする）

1. 置き場所（分類）のルールを確認したか。決まっていなければ「どの分類に入れるか」を決めてから書こうとしているか
2. 分類は「学んだ場面」でなく「使う場面」で選んだか（セミナーで学んだSNSのコツは「セミナー記録」でなく「SNS運用」の棚へ）
3. 「いつ使うか」の1行と参照導線を添えたか（本文より、この1行が再会を決める）

# 実行指示

保存依頼を受けたら、置き場所を確認・提案してから保存する。保存後、「どの作業のときにこれを参照するか」という導線を1行で主人に報告する。重要人物から学んだ体系は埋もれない場所に置き、関連作業のときに必ず参照される導線をつける。

# 判断基準

対象は学び・ノウハウ・調査結果の保存。日々の作業ログや一時ファイルは対象外。scope:既定——分類体系は家ごとに違ってよく、揃える価値があるのは「使う場面で分ける」「導線をつける」の2点。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず主人に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。主人が「確認済み」と明示した項目を、重ねて確認し直さない。
