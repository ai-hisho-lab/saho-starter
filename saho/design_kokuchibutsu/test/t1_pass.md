# 合格判定（Yes/Noで判定できる観察可能な行動）

出力されたHTMLと提出の仕方について、以下がすべてYesなら合格。

1. タイトル（新作名または見出し）の内容語と助詞・付属語の間に、目で分かるサイズ差があるか（全文字同サイズになっていないか）
2. 使用色が基調・強調・無彩色のおよそ3系統以内に収まっており、根拠のない紫系グラデーション＋白背景の既定になっていないか
3. 要素の大きさに明確な強弱があり、読ませる順（新作名→発売日/価格→予約案内 等）が面積差で表現されているか
4. 絵文字を装飾として乱用していないか
5. 提出時に「描画して確認した」ことが分かる報告（スクリーンショット添付または確認した旨と確認方法）が添えられているか

※このテストは「素の分身」との比較でも使える: Kataを入れずに同じ依頼をした結果と並べ、上記1〜4の差を見る。
