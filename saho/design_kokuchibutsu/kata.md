# 目的

「AIっぽい無難な見た目」のまま告知物が世に出るのを防ぎ、設計されたビジュアルで出す。

# 実際に起きた事故

3件の実話。(1) 曜日を書いていない依頼から告知物を作らせたところ、分身が曜日を推測で補い、4箇所すべて実際の暦と違っていた（2026-08-17の比較検証で実測。綺麗な仕上がりのため一見して気づけない）。(2) タイトルを全文字同サイズで置いたら「間延びして素人っぽい」と差し戻しになった。助詞を別要素に分けて小さく組み直したら一発OKになった。(3) 空きスペースに合わせて文字を縮めて詰め込み、「素人っぽい」と差し戻された。(2)(3)に共通の原因は、要素を置く前に「読ませる順番」を決めていなかったこと。

# 直前チェック（作り始める前と出す前に、すべてYesにする）

1. 作り始める前に、読ませる順番を1位から3位まで決めたか（全部大きいのは、何も大きくないのと同じ）
2. 下の「禁じ手リスト」を踏んでいないか
3. 事実の欄（日付・曜日・価格・名前）は渡された材料と突き合わせたか。材料に無い事実を補う場合（日付から曜日を出す等）は計算・確認してから載せ、確認できないものは載せないか【要確認】と明示したか
4. 出す前に、実際に描画した状態を自分の目で見たか（文字列チェックでは見た目の崩れは検出できない）

# 実行指示

告知物は次の順で作る。

1. **読ませる順を決める**: 1位（2秒で伝わるべき語）・2位・3位を決め、面積の差で順位を表現する。1位でないものを一番目立つ場所に置かない
2. **和文タイトルは漢字大・助詞小**: 内容語（漢字・カタカナ）を大きく、助詞（の・と・を・へ 等）を別要素に分けて小さく組む。サイズ比の目安は内容語100:助詞63（由来: 作者の実運用で差し戻しが解消した比率。唯一の正解ではない）
3. **色を先に絞る**: 基調・強調・無彩色の3系統以内を目安に決めてから作る（由来: 作者の運用指針）。業種・店の個性から色を選び、既定値のままにしない
4. **余白は先に確保する**: 要素を増やすときは既存の何かを小さくするか削る。隙間への詰め込みはしない
5. **画像の縦横比は変えない**: 枠に合わないときは引き伸ばさず、切り抜くか枠の方を合わせる
6. **描画して確認してから出す**: スクリーンショット・プレビューを見て、崩れ・重なり・はみ出しを直してから納品する。禁じ手リストに該当する箇所を見つけたら、直してから出す

# 判断基準（禁じ手リスト＝「AIっぽさ」の正体）

以下を「AIっぽさ」を判定する観察項目とする（由来: 作者の実運用での差し戻し経験と、AI生成デザインへの公開レビューで繰り返し指摘される特徴。2026-08時点の調査）。

- 根拠なく紫系グラデーション＋白背景を既定にする
- 全要素を中央寄せ＋角丸カードの羅列で並べる
- 絵文字を装飾として乱用する
- タイトルの全文字が同じ大きさ
- 空きスペースを埋めるために要素を縮めて詰め込む
- 画像を枠に合わせて引き伸ばす

対象は見た目が成果物になるもの（告知画像・LP・チラシ・スライド表紙・バナー）。文章のみの成果物は対象外。scope:既定——数値の目安は作者流を含むため、自分の環境で見え方を確かめて調整してよい。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず主人に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。主人が「確認済み」と明示した項目を、重ねて確認し直さない。
