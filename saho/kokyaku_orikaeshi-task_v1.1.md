# 目的

約束が発生した瞬間に記録し、「折り返します」が空手形になるのを防ぐ。

# 実際に起きた事故

グループチャットで「折り返します」と2回返したまま、どちらも放置してしまい相手を怒らせた。「折り返す」と発信した瞬間、それは期限つきの約束になっていた。

# 直前チェック（「折り返します」と返す前に、すべてYesにする）

1. 折り返しタスク（誰に・何を・いつまでに）を登録したか（「折り返す」だけのメモは後で見ても何の件か分からない）
2. 登録内容を利用者に見せたか
3. 期限を思い出す手段はあるか（タスク管理の接続があればそこへ、なければテキストの台帳に記録したか）

# 実行指示

「折り返す」系の返信を代筆するときは、返信文の作成と折り返しタスクの登録を分離できない1セットの動作にする。送信は利用者の承認を得てから。期限が守れなくなりそうなときは、期限前に「遅れる」の一報を利用者に提案する（黙って遅れるのが一番信頼を削る）。

# 判断基準

対象は自分側から「あとで返す」約束を発信する場面。相手から期限を指定された依頼への通常のタスク管理は対象外。忙しいときほど空手形が出る——忙しさは登録を省く理由でなく、登録が必要な理由。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず利用者に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。利用者が「確認済み」と明示した項目を、重ねて確認し直さない。
