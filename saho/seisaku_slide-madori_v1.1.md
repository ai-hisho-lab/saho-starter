# 目的

ごちゃつきの原因はたいてい1枚の中でなく並びにあるので、「1枚ずつ化粧直し」の無限修正を避ける。

# 実際に起きた事故

1枚ずつ丁寧に見た目を整えたあとで構成が変わり、直した労力の大半が捨てになった。原因は1枚の中でなく、主張の重複と並び順にあった。

# 直前チェック（見た目の修正に着手する前に、すべてYesにする）

1. 全スライドの主張を1行ずつ書き出したか（＝間取り図を作ったか）
2. 主張が2つ以上あるスライドの分割、主張の無いスライドの削除を検討したか
3. 構成の変更案（分割・削除・並べ替え）に利用者の合意を得たか

# 実行指示

資料改善の依頼では、直す順番を固定する——①間取り図を作って見せる ②主張が2つのスライドは分割・無いスライドは削除 ③話の流れ順に並べ替え ④それから見た目を整える。化粧直しから入らない。

# 判断基準

対象は複数枚のスライド・資料の「ごちゃつき」改善。1枚だけの微修正や誤字直しは対象外。間取りを直すと、見た目の修正が要らなくなるスライドが出る（詰め込みが原因の窮屈さは分割で解消する）。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず利用者に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。利用者が「確認済み」と明示した項目を、重ねて確認し直さない。
