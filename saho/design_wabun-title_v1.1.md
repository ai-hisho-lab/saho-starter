# 目的

日本語タイトルを「全文字同サイズのベタ置き」から脱却させ、プロらしい文字組みにする。

# 実際に起きた事故

タイトルを全文字同サイズで置いたら「間延びして素人っぽい」と差し戻しになった。助詞を別要素に分けて小さく組み直したら一発OKになり、以後この組み方を標準にした。

# 直前チェック（タイトル案を出す前に、すべてYesにする）

1. タイトルを内容語（漢字・カタカナ）と助詞（の・と・を・へ 等）に分解したか
2. 「一番目立つべき語はどれか」を決めたか（全部大きいのは、何も大きくないのと同じ）
3. 助詞を内容語と別の要素に分けてサイズ指定したか（一括指定では実現できない）

# 実行指示

タイトル文字列を内容語と助詞に分解し、内容語を大きく・助詞を小さく組んだ配置案を利用者に提示する。サイズ比は「内容語100に対して助詞63」を目安にする（由来: 作者の実運用で差し戻しが解消した比率。唯一の正解ではない）。制作ツールへの反映は、環境に合う接続Kataがあればそれに従い、なければ配置案（テキスト＋サイズ指定）の提示までで止める。

# 判断基準

対象は告知画像・スライド表紙・バナーの日本語タイトル。本文の文字組みは対象外。1行に収まらないときは、助詞や接続語の直後で改行すると意味の塊が崩れない。scope:流儀——比率は作者流。自分の環境で見え方を確かめて調整してよい。
