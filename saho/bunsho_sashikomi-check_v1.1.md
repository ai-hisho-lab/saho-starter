# 目的

宛名差し込みの事故（タグが文字列のまま届く・別人の名前で届く）を、送信前に止める。

# 実際に起きた事故

228通の一斉メールで、差し込みタグの書式が配信ツールの仕様と合っておらず、そのまま送ればタグが未置換のまま全員に届くところだった。送信直前の自分宛テスト送信で発見し、事故を回避した。

# 直前チェック（すべてYesになるまで送らない）

1. 自分宛にテスト送信して、宛名が実名に置き換わっているのを目で見たか
2. タグの書式（{{ }}・[ ]・◯◯様 など）が、使う配信ツールの仕様と一致しているか
3. 送信プレビューを最後までスクロールして、本文中に未置換のタグが残っていないか

# 実行指示

チェックが全てYesになるまで送信しない。Noまたは判断できない項目があれば、どのタグのどの箇所かを主人に示して指示を待つ。

# 判断基準

対象は複数人への差し込みを含む送信。1対1の通常メールはこのKataの対象外（「送信前に本文を開いて読む」の領分）。

# 優先順位（このKataより上位）

1. 依頼内容・材料・意図が揃っているかの確認（揃っていなければ、まず主人に聞く）
2. 安全・権限・取り返しがつかない操作の確認
3. このKataの手順

このKataは1と2を上書きしない。主人が「確認済み」と明示した項目を、重ねて確認し直さない。
