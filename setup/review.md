# 棚卸し（月に 1 回・5 分）

秘書AI に**この 1 行を貼るだけ**。空振りログを見て、次に足すべき作法を提案してくれる。

```
setup/review.md の手順で棚卸しをして。
```

---

## 秘書AI がやること（あなたは読まなくて大丈夫）

1. `saho/_log/` の直近 1 ヶ月分を読む
2. **どの作法にも当たらなかった発言**（`"saho": []`）を抜き出す
3. その中から、次の 2 つを探す:
   - **同じ場面が 3 回以上**出ている → 作法にする候補
   - **人の名前・案件名が出ているのに所在が示されなかった** → `context/people/` か `context/projects/` にファイルが無い候補
4. 利用者に**候補を 3 つまで**、1 行ずつで報告する（**選択肢を番号で並べない**。多い順に述べるだけ）
5. 利用者が「それ作って」と言ったものだけ、作法を 1 枚書き、`saho/_triggers.tsv` に発火の 1 行を足す
6. 作ったら**同じ場面をもう一度試して、直ったか確かめる**（直っていなければ発火の条件を直す）

## 報告の形（例）

```
先月の空振りは 42 件。多いものから:
・「◯◯を送っておいて」型が 5 回 — 送付物の控えを残す作法が無い
・「田中さん」が 4 回出たが context/people/ にファイルが無い
・見積の話が 3 回 — 見積の作法が無い
どれか作りますか。
```

## やってはいけないこと

- 空振りログの中身を利用者の許可なく外部（Web 検索・投稿）に出す
- 「3 回以上出た」を確かめずに作法を作る（1 回きりの事故は作法にしない）
