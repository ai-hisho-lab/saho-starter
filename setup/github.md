# GitHub のアカウントを作って、招待を受ける

利用者から「**setup/github.md のとおりに進めて**」と言われたら、この手順だけを実行する。

作法集（会員向けの作法のまとまり）を受け取るために使う。**無料**。

- **このカードの話だけをする。** 作法集の取り込み自体は `setup/shelf_import.md` の仕事。ここではやらない

## 【あなたにやってもらうこと】

1 手ずつ案内する。**まとめて言わない。**

1. https://github.com/signup を開く
2. **メールアドレス**を入れる（普段使っているもので大丈夫）
3. **パスワード**を決める
   - 15 文字以上、または「8 文字以上＋数字＋小文字」が必要
4. **ユーザー名**を決める
   - **半角の英数字**。世界で 1 つなので、よくある名前は先に使われている
   - 「すでに使われています」と出たら、**数字や記号（-）を足す**（例: `yumi-kobayashi2026`）
   - 本名でなくてよい
5. 「**Japan**」を選んで、案内にそって進む
   - 途中で「人間かどうか」の簡単なパズルが出る
   - 最後に、メールに届く **8 桁の数字**を入れると完了
6. 使い道を聞く画面が出たら、**すべて飛ばしてよい**（Skip）。プランは「**Free**」を選ぶ
7. 決めた**ユーザー名**を、講座の担当者に伝える

## 招待が届いたら

担当者がユーザー名あてに招待を送る。GitHub から

```
invited you to collaborate
```

という件名のメールが届くので、

1. そのメールを開く
2. 中のボタンを押す
3. 緑色の「**Accept invitation**」を押す

## ユーザー名が分からなくなったとき

1. github.com を開く
2. 右上の丸いアイコンを押す
3. 一番上に出てくる**英数字の名前**がユーザー名

## うまくいかないとき

| 症状 | 対応 |
|---|---|
| ユーザー名が「すでに使われています」 | 数字や `-` を足してもらう |
| 確認メールが届かない | **迷惑メールフォルダ**を見てもらう |
| パズルが通らない | 何度かやり直してよい。それでもダメなら**別のブラウザ**で試す |
| 招待メールが見つからない | https://github.com/ai-hisho-lab/saho-kit/invitations を開いてもらう |
| 会社の PC で登録できない | **そこで止める。** 個人の端末でも後から作れると 1 行伝えて終わる |
