# 秘書フォルダの状態レポート（利用者が講師に送るためのもの）

利用者から「**秘書フォルダの状態を教えて**」「**レポート出して**」と言われたら、この手順で表を 1 つだけ出す。

## 絶対に守ること

- **中身は書かない。件数と有無だけ**書く。
  赤レーンの内容・業界用語・人の名前・案件名は**1 文字も出さない**（利用者がこの表をそのまま講師に送るため）
- 呼び名だけは書いてよい（利用者が自分で決めた名前なので）
- 表以外の説明を足さない。**そのままコピーして送れる形**で出す

## 数えるもの

| 項目 | 数え方 |
|---|---|
| 導入 | `setup/_done.txt` があれば「完了」。無ければ `setup/_progress.txt` の最大の数字を見て「Step N まで」 |
| 呼び名 | `CLAUDE.md` の 1 行目から取る。無ければ「未設定」 |
| 渡さない情報 | `governance/security.md` の「この秘書フォルダの赤レーン」の項目数。ファイルが無ければ「未作成」 |
| 業界用語 | `brain/glossary.md` の `- **` で始まる行数。無ければ 0 |
| 作法 | `saho/` 直下の `.md` の数（`README.md` と `_` で始まらないものも含めて全部） |
| 発火行 | `saho/_triggers.tsv` の**総行数**（`#` の行も空行も含めた行数） |
| 会員の作法集 | `saho/_triggers.tsv` に `_sirabete-kara` の行があれば「取込済」、無ければ「未取込」（行数では判定しない） |
| 人のメモ | `context/people/` の `.md` の数 |
| 案件のメモ | `context/projects/` の `.md` の数 |
| 空振り | `saho/_log/` の中の行数の合計。フォルダが無ければ 0 |

## 出す形（これをそのまま）

```
【秘書フォルダの状態】2026-00-00
導入: 完了 / 呼び名: ◯◯
渡さない情報: 3件 / 業界用語: 5件
作法: 14枚 / 発火行: 29行 → 会員の作法集 取込済
人のメモ: 2件 / 案件のメモ: 1件 / 空振り: 0件
```

最後に 1 行だけ添える:

> この表には中身は入っていません。そのまま講師に送って大丈夫です。
