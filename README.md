# AI秘書 スターターキット

AI秘書講座（AI秘書ラボ）の配布物です。

## ダウンロード

**→ [AI秘書.zip をダウンロード](https://github.com/ai-hisho-lab/saho-starter/releases/latest/download/AI-hisho.zip)**

## 使い方

1. 上のリンクから ZIP をダウンロードして、展開する（デスクトップでもダウンロードフォルダでも、どこでも構いません）
2. `AI秘書` というフォルダができます。これがあなたの AI秘書の家です
3. そのフォルダを **Claude のデスクトップアプリで開く**
4. 出てくる確認（このフォルダを信頼しますか）に **はい** と答える
5. `START_HERE.md` にある下の 1 行を貼って送信する

```
setup/onboarding.md を読んで、その手順どおりに私を案内してください。
```

あとは秘書AI が 1 問ずつ案内します。所要 15〜20 分。

## 必要なもの

- **Claude のデスクトップアプリ**（Pro プラン・月約 3,000 円）。これ 1 つで動きます
- **アプリを動かすための道具**（アプリが求めてきます。指示どおり入れてください）
  - **Windows** → **Git for Windows**（青い画面のインストーラーが出ます）
  - **Mac** → **コマンドライン・デベロッパ・ツール**（「インストール」を押すだけ）
- Node.js と Python は要りません（Windows は PowerShell、Mac は sh で動きます）
  - ※ **Git（ギット）と GitHub（ギットハブ）は別物**です。上で入れるのは **Git**（アプリを動かす道具）。
    **GitHub** は会員の棚を受け取るためのアカウントで、インストールするものではありません

## 中身

`START_HERE.md` に全部書いてあります。
